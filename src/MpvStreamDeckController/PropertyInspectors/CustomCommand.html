Syntax and examples

Same format as an mpv input.conf line. Use double quotes for arguments containing spaces.

Unlike input.conf, ${property} is only expanded when "Expand" is ticked, and nothing is shown on the OSD unless an OSD mode is chosen. Prefixes typed in the command (e.g. raw, osd-msg) override both.

cycle pause
seek 30 relative
add volume -5
script-message my-script "hello world"
seek 5 relative; cycle mute
