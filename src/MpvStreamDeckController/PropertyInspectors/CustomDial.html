Syntax and examples

Each command uses the same format as an mpv input.conf line; separate several commands with ;. The clockwise and anticlockwise commands run once per dial tick. Leave a field empty if that part of the dial should do nothing.

The dial itself shows no value. Choose an OSD mode to have mpv show the result on screen, or add a show-text command with "Expand" ticked.

Video zoom:
add video-zoom 0.1 / add video-zoom -0.1 / set video-zoom 0
Subtitle size:
add sub-scale 0.1 / add sub-scale -0.1 / set sub-scale 1
Brightness, shown on screen:
add brightness 1; show-text "Brightness ${brightness}"
