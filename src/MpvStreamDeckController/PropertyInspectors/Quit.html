About these settings

Position: when ticked, mpv saves the playback position before closing (quit-watch-later) and resumes there the next time the file is opened.

This does not work if no-resume-playback (resume-playback=no) is set in your mpv.conf: mpv still saves the position but doesn't restore it.

When unticked, the key sends a plain quit; mpv then only saves the position if save-position-on-quit is set in your mpv.conf.
